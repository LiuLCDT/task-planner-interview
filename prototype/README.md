# 额度体验交互原型

产品方向交付，HTML/CSS/JavaScript，无安装依赖、无真实模型调用、无后端连接。保留原项目源码，原型单独放在此目录。

从仓库根目录运行 `python3 -m http.server 4173 --directory prototype`，访问 `http://localhost:4173`。也可直接打开 `index.html`。

使用左侧“演示场景”体验正常生成、最后一次额度、额度耗尽、明确失败和同账号重叠请求。并发场景预设同账号另一页面持续占用生成资格，用户点击本页生成后仅展示拦截 toast，不发起本页调用、不扣费。切换场景或重置解除占用；不模拟另一页完成结算，不代表真实跨页面互斥。刷新会重置所有演示数据。

- 默认 3 次额度；成功消耗 1 次，失败不消耗。
- 同账号一次只受理一份；处理中再次请求会被拦截。
- 自定义 tooltip 支持鼠标、键盘和触屏，不使用原生 title。
- 原型延迟为 1.8 秒，便于观察中间状态；原仓库模拟接口约 500 毫秒。
- 原型不是原项目后端的额度修复，不可作为生产代码或后端并发验证证据。

验证详情见 [验证记录](../docs/product/VERIFICATION.md)。

## 与题目原前端的关系

以 `src/demo-ai-app/DemoAppPage.tsx` 的单列「待办 → 可用时长 → 生成 → 本次日程」为基础展示额度体验；配色、元信息与独立演示控制为原型表现层。生成前待办完成勾选、逐项时长、主题切换和退出登录保留为静态占位，不执行操作、不弹提示。日程结果的完成勾选仍可交互；登录和持久化未实现，刷新会重置，不表示建议从正式产品删除。

生成内容沿用 `src/demo-ai-app/mockAi.ts` 的固定「准备／执行／复盘 + 任务名」、中优先级和平均分配逻辑，不代表 AI 内容质量；显示分钟采用整数余数分摊，避免原接口小时四舍五入产生的总分钟偏差。加载期间保留已有日程的占位，避免结果区反复收缩。

账号栏展示演示账号与退出登录入口占位，不执行认证操作。普通场景自动运行，并发场景需手动点击生成。
